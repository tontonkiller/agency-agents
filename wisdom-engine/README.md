# The Wisdom Engine — Prototype v0.1

Premier proto textuel du Wisdom Engine : 3 agents philosophiques guident le joueur à travers une mission à Venise.

## Lancer le jeu

```bash
python3 wisdom-engine/game.py
```

Aucune dépendance externe requise — Python 3.7+ suffit.

## Ce que fait ce proto

- **3 agents philosophiques** : Laozi (Taoïsme), Marc Aurèle (Stoïcisme), Simone de Beauvoir (Existentialisme)
- **1 mission en 3 actes** : "The Invisible Hand" — renverser un Doge corrompu à Venise
- **Profil de progression** : radar ASCII montrant l'évolution philosophique du joueur
- **Choix significatifs** : chaque décision affecte le profil et mène à une fin différente
